# Estoque com RabbitMQ e Supabase

## Variáveis de Ambiente (.env)

```env
PORTA=3000
SUPABASE_URL=sua_url_do_supabase
SUPABASE_KEY=sua_key_do_supabase
RABBITMQ_URL=amqp://admin:admin@localhost:5672
```

## Subir o RabbitMQ

```bash
docker-compose up -d
```

Painel do RabbitMQ: http://localhost:15672 (usuário `admin`, senha `admin`)

## Comandos SQL (Supabase)

Os comandos estão em `sql/banco.sql`:

```sql
ALTER TABLE produtos ADD COLUMN IF NOT EXISTS estoque_minimo INTEGER DEFAULT 5;
ALTER TABLE produtos ADD COLUMN IF NOT EXISTS disponivel BOOLEAN DEFAULT true;

CREATE TABLE IF NOT EXISTS movimentacoes_estoque (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    evento_id UUID UNIQUE NOT NULL,
    produto_id BIGINT REFERENCES produtos(id),
    tipo TEXT NOT NULL,
    quantidade INTEGER NOT NULL,
    saldo_anterior INTEGER NOT NULL,
    saldo_atual INTEGER NOT NULL,
    criado_em TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS alertas_reposicao (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    produto_id BIGINT REFERENCES produtos(id),
    saldo_atual INTEGER NOT NULL,
    estoque_minimo INTEGER NOT NULL,
    status TEXT DEFAULT 'PENDENTE',
    criado_em TIMESTAMPTZ DEFAULT NOW()
);
```

## Executar o Projeto

Instalar dependências:

```bash
npm install
```

Rodar a API e os 3 workers (um em cada terminal):

```bash
node index.js
npm run worker:auditoria
npm run worker:compras
npm run worker:vitrine
```

## Rota de Movimentação

`POST /produtos/:id/movimentar`

